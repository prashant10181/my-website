# Shishant Advanced Portfolio

## Files
- `index.html` — page structure/content
- `style.css` — design, responsive layout and animations
- `script.js` — theme switcher, particles, project modals and mobile menu

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
Upload all three files to the root of your GitHub repository and enable:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Activate the contact form
The form is prepared for Formspree. Create a free form at https://formspree.io/ and replace:
https://formspree.io/f/YOUR_FORM_ID
with your real Formspree endpoint in `index.html`.

Do not put passwords, API keys, or other secrets into this public repository.
